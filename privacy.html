Privacy Policy

Last updated: 31 October 2026

1. What this is

gog is a personal, locally installed command-line application (openclaw/gogcli). It lets its single operator access their own Google Workspace data — Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets and Google Contacts — from a terminal on their own computer.

2. What data is accessed

With the operator's explicit consent through Google's OAuth 2.0 authorization screen, gog may access: Gmail messages and settings; Google Calendar events; Google Drive files; Google Docs documents; Google Sheets spreadsheets; and Google Contacts, depending on the scopes the operator grants. The OAuth scopes requested are limited to those needed for the features the operator chooses to authorize.

3. How data is used

Data is retrieved only when the operator runs a command, and is used only to display or modify that operator's own data as instructed by the operator. Data is not used for advertising, profiling, analytics or model training.

4. Where data is stored

This application has no server, no hosted backend and no database. Data retrieved from Google is held only in the memory of the operator's own computer for the duration of the command, or written to a local file only when the operator explicitly requests an export. OAuth credentials and refresh tokens are stored in the operating system's credential manager (Windows Credential Manager on this machine) and are never transmitted anywhere except to Google's own OAuth endpoints.

5. Sharing

No Google user data is sold, rented, shared, transferred or disclosed to any third party. No third-party analytics, trackers or advertising services are used. Network traffic goes only to Google APIs (*.googleapis.com) and the OAuth endpoints at accounts.google.com.

6. Retention and deletion

gog retains no copy of Google user data after the command completes. The operator can revoke access at any time via Google Account permissions, or by deleting the stored credentials with the application's auth commands; the refresh token is then permanently removed from the local credential store.

7. Your controls

Access is granted solely by the account owner through Google's consent screen. The operator may decline or revoke any scope, and may run the tool in read-only mode. Google's own policies also apply to the data.
