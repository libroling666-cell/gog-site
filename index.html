gog — Google Workspace CLI

A personal command-line tool for Gmail, Calendar, Drive, Docs, Sheets, and Contacts.

gog is a locally installed, open-source command-line client (openclaw/gogcli) used to read and manage a single person's own Google Workspace data from a terminal.

It runs entirely on the user's own computer. It authenticates directly with Google using the user's own Google Cloud OAuth client and stores the resulting OAuth refresh token in the operating system's credential store (Windows Credential Manager on this machine). There is no server operated by this project and no third-party data storage.

Typical usage:

gog gmail search 'newer_than:7d' --max 10
gog calendar events --today
gog drive ls --max 20
